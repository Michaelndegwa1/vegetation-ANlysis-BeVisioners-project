## Open questions
- Q1 Validation independence (design in 03a: train on WorldCover pseudo-labels, validate on human labels; user capacity still needed): Hansen/WorldCover labels cannot both train and validate (circular). Needs independent reference points, e.g. visual interpretation of high-resolution imagery by the user on a stratified sample per site (n to be set). Decide before 03a.
- Q2 Forest definition in dryland sites: DECIDED 2026-11-24 by the user: the monitored class is WOODY VEGETATION (tree + shrub), not Hansen 'forest'. Remaining work: independent labels (Q1) and a non-Hansen baseline (Q3, GEDI/Landsat). Evidence: Share of site area by Hansen treecover2000 (2025_v1_13, 90 m): Kasigau I 98.7% of pixels at 0-9% cover, >=30%: 0.1%; Kasigau II >=30%: 0.0%; Chyulu 73.9% at 0-9%, >=30%: 6.7%. ESA WorldCover 2021 (30 m): Kasigau I shrub 72.5% / tree 0.6% / grass 26.2%; Kasigau II shrub 92.1% / tree 0.2%; Chyulu tree 18.5% / shrub 23.7% / grass 50.8% / crop 5.1%. So Hansen cannot define the baseline or training labels at Kasigau (dryland thicket/shrubland), and a 'forest' classifier would be mostly empty. Options for the user: (a) define the monitored class as woody vegetation (tree+shrub) for dryland sites, with independent labels (Q1); (b) restrict the supported sites to those with real Hansen forest; (c) use GEDI canopy height/biomass or Landsat NDVI history for the baseline. Recommendation: (a)+(c), since Kasigau REDD+ protects dryland woody vegetation by design.
- Q3 Pre-2019 baseline: Hansen only, or add Landsat? Verify Landsat collection IDs and cloud handling.
- Q4 GEDI L4A biomass (optional): the collection exists (67,000 monthly images); sampling is sparse, so treat it as a site-level indication only.
